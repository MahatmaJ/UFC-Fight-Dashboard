# UFC-Fight Analysis-Dashboard

An interactive Plotly Dash dashboard analyzing over 8,700 UFC fights spanning 1993–2025. The dashboard surfaces trends across win methods, significant-strike accuracy by weight class, the relationship between control time and win rate, and win rate by fighter stance (with a click-to-drill-down view by weight class) — plus a head-to-head fighter search and comparison tool with radar-chart visualizations. 

Built end-to-end in Python with Pandas for data processing and Plotly/Dash for the interactive front end, styled with a custom UFC-inspired dark theme, and deployed as a publicly accessible web app via Render.
